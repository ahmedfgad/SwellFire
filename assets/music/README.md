# Background music

Eight composed loops, generated by `tools/gen_world_music.py` (numpy synth,
dev/build-time only — not a runtime dependency):

- `bg_music_menu.wav`   — title screen, upbeat playful theme
- `bg_music_world1.wav` — Meadow, cheerful pastoral bounce
- `bg_music_world2.wav` — Desert, exotic groove
- `bg_music_world3.wav` — Industrial, funky electro-groove
- `bg_music_world4.wav` — Snowfield, sparkly crystalline
- `bg_music_world5.wav` — Volcano, heroic action march
- `bg_music_world6.wav` — Cosmos, dreamy synthwave
- `bg_music_boss.wav`   — boss fights, epic battle theme

All are 44.1 kHz / 16-bit / mono, ~20 s seamless loops (played with
`loop=True` by `audio.py`). Re-generate with `python tools/gen_world_music.py`
(`--only world3,boss` to rebuild a subset). The stdlib
`tools/gen_placeholder_audio.py` remains as the minimal-placeholder fallback
generator but no longer produces the shipped music.
