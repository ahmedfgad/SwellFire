# Replacement Background Music — All Tracks

**Date:** 2026-05-29
**Status:** Approved design (pending spec review)

## Problem

All background music in `assets/music/` is intentionally-minimal placeholder
audio generated by `tools/gen_placeholder_audio.py` (stdlib sine/square/noise
synthesis, ~4 s loops). The `README.md` in that folder flags it as placeholder
"to be replaced in the M14 asset pass" — which never happened.

Several tracks are perceived as *noisy* — especially **W3 (Industrial)** hard
square-wave power chords, **W5 (Volcano)** square stabs, and **W6 (Cosmos)** a
2400 Hz "glitch" sine. The rest are thin 4-second sine loops that grate on
repeat.

**Scope:** replace **every** music track — menu, worlds 1–6, and the boss
track (8 files total) — with higher-fidelity, pleasant, melodic loops.

## Decisions (confirmed with user)

- **Approach:** Use a synth library (numpy) for higher fidelity, rather than
  staying stdlib-only. This is a **dev/build-time tool**, not a runtime/app
  dependency — identical posture to Pillow in the asset pipeline. numpy is NOT
  added to `buildozer.spec` (mobile build stays `python3,kivy`); the WAVs ship
  pre-generated as assets.
- **Vibe per track** (kid-friendly, lively, *clean*):
  - **Menu → Upbeat playful theme**: catchy cheerful main-theme melody with a
    light bounce; welcoming, energetic.
  - **W1 Meadow → Cheerful pastoral bounce** (~104 BPM): bright major-key tune,
    happy hopping rhythm; sunny, gentle first world.
  - **W2 Desert → Exotic desert groove** (~100 BPM): warm mid-tempo, exotic
    (harmonic-minor / "Middle-Eastern"-flavored) scale, hand-percussion feel.
  - **W3 Industrial → Funky electro-groove** (~112 BPM): clean filtered-saw funk
    bassline, bright plucky lead riff (minor-pentatonic), soft kick +
    filtered-noise hat. Danceable; industrial identity without buzz.
  - **W4 Snowfield → Sparkly crystalline** (~96 BPM): bright bell/arpeggio
    melody with shimmer over a cool pad; icy, magical, twinkling.
  - **W5 Volcano → Heroic action march** (~128 BPM): driving kick+snare, stacked
    detuned-saw synth-brass triumphant rising melody (major/Lydian), power-chord
    pad. Intense but tuneful — no hard square stabs.
  - **W6 Cosmos → Dreamy synthwave** (~92 BPM): warm detuned-saw pad chords,
    shimmering sine/triangle arpeggio through a delay, smooth round bass, gentle
    backbeat. The 2400 Hz glitch is removed entirely.
  - **Boss → Epic battle theme** (~140 BPM): high-tension driving beat +
    dramatic minor-key synth-orchestral melody; climactic "big fight" energy.
- **Format:** 44.1 kHz, 16-bit, **mono**, ~20 s seamless loop per track.
  ≈ 1.7 MB/file → ≈ **14 MB total** across 8 tracks (up from ~360 KB total).
  Accepted fidelity↔size trade. (If APK size becomes a concern later, dropping
  to 22.05 kHz roughly halves it without re-composing.)

## Architecture

New module **`tools/gen_world_music.py`** (numpy-based), kept separate from the
stdlib `gen_placeholder_audio.py` so the simple placeholder pipeline is
untouched. It writes all eight files into `assets/music/`:
`bg_music_menu.wav`, `bg_music_world1.wav` … `bg_music_world6.wav`, and
`bg_music_boss.wav`, overwriting the placeholders.

Because the filenames are unchanged, **no runtime code changes** are needed:
`audio.py` loads them with `loop=True` and picks up the new files automatically.

### Synth core (small, reusable, inside the module)

- **Oscillators:** sine, triangle, band-limited saw, and "soft square" built by
  summing a bounded set of harmonics — band-limiting avoids the aliasing buzz
  that makes the current placeholders harsh.
- **Envelope:** ADSR shaped to each note buffer.
- **Filter:** a low-pass (one-pole or biquad) to tame brightness on the
  saw/brass voices — the main lever for "clean, not buzzy."
- **Space:** a simple feedback delay / cheap reverb send for arps and pads.
- **Percussion:** synthesized kick (pitch-swept sine), snare/hat (enveloped
  filtered noise) — used by the groovier tracks.
- **Helpers:** note-name/MIDI → frequency; bar/beat timing from BPM; a tiny
  sequencer helper that places notes on a beat grid.
- **Master:** sample-wise mix, normalize-to-peak, gentle soft-clip (tanh) to
  prevent hard clipping.

### Per-track builders

One `build_<name>()` per track renders its layers (bass / lead / pad / drums)
into float arrays at the track BPM for a whole number of bars totalling ~20 s,
mixes them through the master chain; the driver writes the 16-bit mono WAV.
Shared chord progressions/melodies are expressed via the note helpers so each
builder stays compact and readable.

### Seamless looping

Loops are **bar-aligned** (integer bars at the track BPM). A short equal-power
crossfade folds the track tail into its head at render time so the boundary is
click-free under Kivy's `loop=True`. The build script logs the measured
boundary discontinuity so seamlessness can be confirmed numerically.

## Out of scope

- Any runtime/`audio.py`/`game.py` changes (filenames unchanged).
- Adding numpy to the mobile build (`buildozer.spec`).
- Stereo output.
- SFX (the `assets/sfx/` bank is unchanged).
- The stdlib `tools/gen_placeholder_audio.py` (left intact as the fallback
  placeholder generator).
