# Swellfire 1.0.2

This release improves the gameplay curve and delivers refreshed builds for
every supported platform from the newly organized project structure.

## What changed

- Rebalanced early-game gates, enemy formations, rewards, and level progression.
- Refined weapon tiers, combat feedback, boss targeting, and projectile behavior.
- Improved gameplay state handling and expanded regression coverage.
- Reorganized runtime code, tests, build scripts, requirements, documentation,
  and marketing assets into clear project directories.
- Updated every desktop, Android, and iOS build workflow for the new layout.

## Downloads

- `Swellfire-1.0.2-android.apk` is the signed Android release APK.
- `Swellfire-1.0.2-linux-x86_64` is the standalone 64-bit Linux application.
- `Swellfire-1.0.2-windows-x86_64.exe` is the standalone 64-bit Windows
  application.
- `Swellfire-1.0.2-macos-arm64.zip` contains the app for Apple Silicon Macs.
- `Swellfire-1.0.2-ios-unsigned.ipa` is the unsigned iPhone and iPad build for
  developer signing and testing. It cannot be installed or submitted to the
  App Store until it is signed with an Apple Developer account.

The Linux download may need executable permission after downloading:
`chmod +x Swellfire-1.0.2-linux-x86_64`.

The macOS app is not Developer ID signed or notarized, so macOS may show a
Gatekeeper warning when it is opened for the first time.
